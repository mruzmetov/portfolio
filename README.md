## About

This is my personal portfolio — built to showcase my projects, skills and experience for employers and clients.

Built with a focus on **performance, clean UI and fast loading** — no heavy templates, everything is custom.

## Features

- ⚡ Fast, SEO-friendly portfolio built with Next.js App Router
- 🎨 Modern, responsive design — mobile-first
- 🧩 Projects, Skills, Experience & Contact sections
- 🌍 Deployed and live at ruzmetov.uz
- ♻️ Easy to update — content is separated from UI

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** JavaScript
- **Styling:** Tailwind CSS / PostCSS
- **Deployment:** Vercel
